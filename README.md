# openpaper（オープンアクセス論文ファインダー）

キーワードや DOI から論文を検索し、**合法的に公開されているオープンアクセス（OA）版がある場合にだけ、その無料フルテキストへ案内する**小さな Web ツールです。

## 大事な線引き

- このツールが案内するのは、出版社や著者自身が合法的に公開しているオープンアクセス版だけです。
- Sci-Hub のような「有料論文を無料で読める」仕組みは作りません。そうしたサイトへのリンクや誘導は一切含みません。
- OA版が見つからない論文については、DOI の公式ページへのリンクのみを表示し、「オープンアクセス版は見つかりませんでした」と明示します。

## 使い方

1. 検索欄にキーワード（例: `self-regulated learning`）を入れて検索すると、該当論文の一覧（タイトル・著者・年・掲載誌・OAステータス）が出ます。
2. DOI（例: `10.1038/s41586-020-2649-2` や `https://doi.org/10....` の形式）を入れると、その論文1件を表示します。
3. 合法的な無料フルテキストがある論文には「無料で読む」ボタン（OA版の PDF またはランディングページ）が出ます。ない論文には出ません。

## 技術構成

- Python / Flask（`app.py`）
- 論文データ: OpenAlex API（`https://api.openalex.org`、APIキー不要）
- 本番起動: gunicorn（Render Free 想定、`render.yaml`）
- API の応答パースは `parse_work()` という独立関数に分離し、pytest でテストしています

## ローカルで動かす

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000 を開く
```

## テスト

```bash
pip install pytest
pytest
```

テストは実 API には接続せず、OpenAlex 応答のフィクスチャとモックで完結します
（OAあり→無料リンク生成／OAなし→リンクなし＋明示文、DOI 判定、画面描画、API 失敗時のエラー表示）。
